## Project Details

### 1. [Pressure Housing]
**OCE205 / Fall 2025:** 
**Type:** Lab report / Excel Calculator / SolidWorks Modeling / Lab Analysis

**Summary:** The goal for this end-of-course project was to design a pressure housing using our knowledge of stress limits and other theoretical principles learned during the semester. We first picked a rough shape we wanted the pressure housing to be, used excel calculators to optimize the dimensions of the pressure housing to increase durability while reducing costs, designed the final product using SolidWorks, learned to draw diagrams to send to manufacturers, learned how to order parts(O-rings), and finally printed the design with our ordered O-ring and tested the capsule in a pressure chamber. 

**My role:** While the project was team based each member of the group contributed to all aspects of the project so I did not hold one role.

**Tools / Methods:** Excel, Latex, and SolidWorks.

**Files:**
- `Cylinder_DrawingFinalV3.SLDDRW`: Full Model Drawing
- `Cylinder_ModelFinalV3.SLDPRT`: Full Model Assembly
- `OCE205_Failure Mode Calculator.xlsx`: Failure Mode Calulator
